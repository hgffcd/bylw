## 文件清单的使用

```bash
python -m reproduce.verify
```

`SOURCE_ORIGINS.json` 为原始源文件哈希，`SOURCE_MANIFEST.json` 为当前导出文件哈希（不含其自身）。此哈希清单用于完整性核对，不是实验结果数据。继续修改代码后应重新生成清单；不要把旧哈希继续宣称为当前源码。
